# Проценка

Тестовое задание: поиск автозапчастей и аналогов через API Favorit Parts.

**Стек:** React, JavaScript, Redux Toolkit, Bootstrap, SCSS, Vite.

## Запуск

Node.js 22 LTS и npm.

```sh
npm ci
cp .env.example .env
npm run dev
```

В `.env.example` указан ключ из примера документации. При необходимости замените `VITE_FAVORIT_API_KEY` своим ключом. После изменения `.env` перезапустите dev-сервер.

## Поиск

Введите артикул и нажмите «Найти» или Enter, затем выберите производителя. В раскрытой карточке детали доступны цены и остатки по складам.

Результаты сгруппированы так, чтобы предложения с большим остатком были выше:

- Искомая деталь показана отдельно от аналогов; предложения одной детали собраны в одной карточке.
- Аналоги отсортированы по суммарному остатку на складах, от большего к меньшему.
- Склады внутри карточки также отсортированы по убыванию остатка.
- Позиции без подтверждённого наличия находятся после доступных.
- Аналоги разбиты на страницы по 20 деталей после сортировки всего списка.

Предусмотрены состояния загрузки, пустого результата и ошибок API. При смене артикула или производителя предыдущий запрос отменяется.

## API

[Документация Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf).

Адрес API задаётся в `VITE_FAVORIT_API_URL`. Доступность и квота ключа зависят от поставщика.

API использует HTTP. Для размещения приложения на HTTPS потребуется серверный прокси. Переменные `VITE_*` доступны в браузере, поэтому приватный ключ следует хранить на сервере. Прокси в проект не входит.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Тесты проверяют обработку ответов API, группировку предложений, кеширование и защиту от устаревших ответов. Внешний API при запуске тестов не используется.

Поиск и выбранный производитель сохраняются в адресе страницы. Работают кнопки браузера «Назад» и «Вперёд»; после обновления поиск восстанавливается.
