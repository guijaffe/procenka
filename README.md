# Проценка

Поиск автозапчастей и аналогов по артикулу.

React, Redux Toolkit, JavaScript, Bootstrap, SCSS, Vite.

## Запуск

Node.js 22 и npm.

```sh
npm ci
cp .env.example .env
npm run dev
```

## Как работает

Введите артикул, нажмите «Найти» или Enter и выберите производителя. Раскройте карточку детали, чтобы увидеть цены и остатки по складам.

В ТЗ указан поиск «по факту ввода». Здесь выбран запуск по кнопке или Enter: так выдача не меняется, пока пользователь дописывает или исправляет артикул.

- Искомая деталь и аналоги показаны отдельно.
- Аналоги и складские предложения отсортированы по убыванию остатка. Позиции без подтверждённого наличия — после доступных.
- На странице — 20 аналогов.
- Адаптивная вёрстка, управление с клавиатуры и переиспользуемые UI-компоненты.
- Состояния загрузки, ошибок и пустого результата.
- Артикул и бренд сохраняются в URL. Работают «Назад», «Вперёд» и восстановление поиска после обновления страницы.
